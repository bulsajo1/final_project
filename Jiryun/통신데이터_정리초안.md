# 통신데이터 정리 초안

이 문서는 튜터님 피드백 기준으로 통신 데이터 작업 전체를 한 번에 볼 수 있게 정리한 정리 초안이다.  
노트북 실행/작업 기록은 `통신데이터_통합.ipynb`, `통신데이터_검증.ipynb`, `통신데이터_EDA.ipynb`에 역할별로 정리했다.

## 튜터님 피드백 반영 순서

1. 노트북 역할 분리: 통합 / 검증 / EDA
2. 예측 변수 후보 테이블 확정: EDA에서 변수로 연결한 테이블 기준
3. 산출물 후보 요약표 작성
4. 재사용 가능 기준 검증: 재불러오기, 행 수, 기간, 핵심 컬럼 타입
5. 변수 후보 연결표 작성
6. 예측 변수 후보 테이블 역할 한 줄 정리
7. 코드값 정의표 작성: 확정 / 추정 / 미확인 구분
8. 기존 작업 기록까지 새 노트북과 정리 초안 문서에 반영

## 노트북 역할

| 노트북 | 역할 | 포함 내용 |
|---|---|---|
| `통신데이터_통합.ipynb` | 원본/중간 파일 통합 및 parquet 후보 확정 | 기존 통합 작업, T4~T11 기초 전처리, T13/T25/T26/T27 전처리 기록 |
| `통신데이터_검증.ipynb` | parquet 후보 재사용 가능 여부 검증 | 재불러오기, 행 수, 기간 범위, 핵심 컬럼 타입, 코드값 상태 |
| `통신데이터_EDA.ipynb` | parquet 후보와 전체 t 데이터 EDA | 전체 t 데이터 구조 파악, 월별/지역별/목적별 분포, 예측용 변수 해석 메모 |

## 모델링용 테이블 선택안

아직 팀의 목표변수와 전체 마스터 테이블이 정해지지 않았으므로, 아래 내용은 확정된 내용이 아니라 **EDA 결과를 바탕으로 한 1차 후보안**이다.

### 추천 분석 단위

| 항목 | 1차 후보 | 이유 |
|---|---|---|
| 분석 단위 | 행정동-월 | 통신, 인구, 매출, 공시지가, 거래량 데이터를 월별 지역 단위로 합치기 가장 안정적 |
| 마스터 키 | `base_ym + admi_cd` | 팀 공통 테이블에 붙이기 쉬운 구조 |
| 통신 데이터 역할 | 설명변수 feature | 젠트리피케이션 자체가 아니라 유동/유입/체류/접근성 proxy |

### 테이블 우선순위

| 우선순위 | 테이블 | 사용 판단 | 이유 |
|---:|---|---|---|
| 1 | T24 | 기본 feature 후보 | 행정동 단위 유동인구라 `base_ym + admi_cd`로 바로 집계하기 좋음 |
| 2 | T13 | 핵심 추가 후보 | 행정동 OD라 외부유입, 유출입 구조, 이동량 증가를 만들기 좋음 |
| 3 | T26 | 핵심 추가 후보 | 도착 행정동 기준 체류시간과 목적 특성을 만들기 좋음 |
| 4 | T27 | 선택 추가 후보 | 이동수단/목적/체류 특성을 보완하되 T26과 중복 확인 필요 |
| 보조 | T25 | 참고 후보 | 시군구 OD라 행정동 모델에서는 해상도가 낮아 보조 지표로 적합 |
| 보류 | T4~T12, T14, T16, T22, T23 | 구조 파악/필요 시 추가 | 중복되거나 모델 단위와 맞추기 전 추가 검토 필요 |

### 1차 추천 조합

`T24 + T13 + T26`으로 먼저 모델 feature를 만들고, 이후 변수 중요도와 중복성을 보고 `T27`, `T25`를 추가한다.

## 파생변수 후보 연결표

| 원천 | 파생변수 후보 | 집계 기준 | 의미 | 사용 방향 |
|---|---|---|---|---|
| T24 | `floating_pop_sum` | `base_ym + ADMI_CD` | 월별 행정동 전체 유동량 | 기본 규모 변수 |
| T24 | `purpose_*_cnt` | `base_ym + ADMI_CD + PURPOSE` | 목적별 유동량 | 생활권/상권 목적 구분 |
| T24 | `purpose_*_ratio` | 목적별 CNT / 전체 CNT | 목적별 유동 비중 | 지역 성격 비교 |
| T24 | `daytime_cnt`, `night_cnt` | `TIME_CD` 기준 | 주간/야간 유동량 | 시간대별 상권 성격 |
| T24 | `night_ratio` | 야간 CNT / 전체 CNT | 야간 유동 비중 | 주거/상권 혼합 특성 |
| T24 | `age_20_40_ratio` | AGE_GRP 기준 | 주요 소비/경제활동 연령층 비중 | 소비층 proxy |
| T24 | `female_ratio`, `male_ratio` | SEX_CD 기준 | 성별 유동 비중 | 이용자 구성 |
| T13 | `inflow_cnt` | 도착 행정동 기준 | 해당 행정동으로 들어온 이동량 | 유입 규모 |
| T13 | `outflow_cnt` | 출발 행정동 기준 | 해당 행정동에서 나간 이동량 | 유출 규모 |
| T13 | `external_inflow_cnt` | 외부 지역 -> 해당 행정동 | 외부유입량 | 외부 수요 증가 proxy |
| T13 | `external_inflow_ratio` | 외부유입 / 전체유입 | 외부유입 비중 | 젠트리피케이션 압력 후보 |
| T13 | `inflow_outflow_ratio` | 유입 / 유출 | 유입·유출 균형 | 지역 활동성 |
| T26 | `avg_stay_time` | 도착 행정동 기준 | 평균 체류시간 | 체류형 상권 여부 |
| T26 | `long_stay_ratio` | 장기체류 CNT / 전체 CNT | 장기체류 비중 | 체류 강도 |
| T26 | `purpose_stay_avg_*` | PURPOSE별 DURATION 평균 | 목적별 체류시간 | 방문 목적별 체류 특성 |
| T27 | `transport_*_ratio` | TRANS_GB별 CNT 비중 | 이동수단별 비중 | 접근성/교통 특성 |
| T27 | `purpose_transport_*` | PURPOSE + TRANS_GB | 목적·수단 조합 | 접근 방식과 방문 목적 결합 |
| T25 | `city_inflow_pressure` | 시군구 OD 기준 | 구 단위 유입 압력 | 행정동 모델의 보조 변수 |

주의: `PURPOSE`, `TRANS_GB`, `AGE_GRP`의 정확한 의미는 공식 정의서 확인 전까지 단정하지 않고 코드값 기준으로 관리한다.
